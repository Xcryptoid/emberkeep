Emberkeep — Last Light of the Hollow: a top-down arena survival game. You are Warden Asha, keeper of the last ember lantern in a drowned hollow. Survive until dawn (5:00), level up through ember gems and upgrade cards, and slay the Gloom Herald that comes for the light.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
